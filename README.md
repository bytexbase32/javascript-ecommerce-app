# Vanilla JS E-Commerce

A client-side e-commerce application built using pure JavaScript.

## Purpose

This project is built to practice modern JavaScript before moving to frameworks and full-stack development.

## Technologies

- HTML
- CSS
- Vanilla JavaScript
- ES6 Modules
- Fetch API
- LocalStorage

## Planned Features

- Product listing
- Product search
- Filtering
- Sorting
- Product details
- Shopping cart
- LocalStorage persistence
- Responsive design
